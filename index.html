    Regras de conversão aplicadas
    O arquivo de saída usa ; como separador e repete as duas linhas de cabeçalho do modelo oficial (NUMERO;VAR1;VAR2;VAR3;VAR4;VAR5 e a linha descritiva). As colunas são localizadas pelo nome no cabeçalho do SINFRA, então a ordem das colunas não importa.
    • NUMERO ← Contatos Paciente: usa o celular (11 dígitos começando com 9 após o DDD). Se houver dois números, usa o primeiro celular válido. Sai no formato 5516988187599 (55 + DDD + número). Fixos são ignorados.
    • VAR1 ← Paciente: nome sem o código do prontuário (remove 123456 - ).
    • VAR2 ← Exame: nome sem o código do procedimento (remove 0211020036 ).
    • VAR3 ← Data do Exame: apenas a data (dd/mm/aaaa).
    • VAR4 ← Data do Exame: apenas a hora (hh:mm).
    • VAR5 ← Unidade exame: mantida como está.
    Tudo roda no seu navegador — nenhum dado é enviado para a internet.
